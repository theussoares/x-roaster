# Product Customizer Documentation

## Overview
This application allows users to customize T-shirts in real-time using Nuxt 3, Fabric.js, and inline SVGs.

## Global Rules Followed
1. **Dumb Components**: Logic is in `composables/useCustomizer.ts`.
2. **Vanilla CSS**: No Tailwind dependencies, custom design system in `assets/css/main.css`.
3. **Architecture**: Clean separation between state management and UI components.

## Development
```bash
npm install
npm run dev
```
